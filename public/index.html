ILM API — DOCUMENTATION

A unified home for Quran, Hadith, and Islamic scholarship

Built for researchers, scholars, and students — Quran with multiple translations and tafsir, all six canonical hadith collections, isnad chains, root-word morphology, thematic cross-references, fiqh comparisons across madhabs, prayer times, and du'as. Free to start.

Try it — read the Quran and search Hadith right now →

Who This Is For

Most Islamic knowledge is scattered — one app for Quran, another for hadith, another for tafsir. This API puts it behind one consistent, searchable, citable interface.

Students get a simplified translation mode, word-by-word Arabic breakdowns with root and grammar, audio recitation, and bookmarking to build a personal study collection.

Researchers get BibTeX/APA citation export, bulk dataset downloads, full-text search across 34,000+ hadith, and narrator chains for authenticity verification.

Scholars get multiple tafsir sources side-by-side, madhab comparisons on fiqh questions, thematic cross-referencing between ayahs and hadith, and Arabic root-word search across the whole Quran.

Authentication

Include your key as a header on every request:

x-api-key: ilm_your_key_here

Bookmarking and study lists use a separate, personal login (POST /v1/auth/signup) — not the developer key above.
